# SI Wallet

v1 prototype of a European Digital Identity (EUDI) Wallet for Slovenia, built with React Native / Expo.

Not a certified EUDI Wallet under Regulation (EU) 2024/1183. Demo/test use only.

- `wallet/` – Expo app (SL / EN)
- `docs/` – EU and Slovenian legal research and the v1 specification (work in progress)
